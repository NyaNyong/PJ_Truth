# 🎮 진실보관소: Truth_Archive

## 📌 프로젝트 개요 (Overview)
<img width="1302" height="625" alt="image" src="https://github.com/user-attachments/assets/df6b870c-f18a-424f-a876-d8627be31038" />

2026학년도 1학기 디지털아트페스티벌 출품작으로, 근미래 디스토피아적 배경에서 정보가 선택적으로 공개되고 통제되는 사회 구조를 다루는 시리어스 게임입니다.
본 작품은 플레이어가 시스템의 일부로서 직접 행동함으로써,
“무엇이 진실인가”보다 “어떤 진실만 남도록 만들어지는가”를 체험하게 하고,
그 과정에서 정보의 이면에 존재하는 구조를 스스로 인식하도록 하는 것을 목표로 합니다.

제작 기간: 2026.03 ~ 2026.06 (약 3개월)

참여 인원: 5인

나의 역할: 인게임 시스템 설계, 개발 전반

사용 기술 및 툴: Unity, Claude

## 🙋‍♂️ 나의 역할 및 기여도 (My Contribution)

[직무 1, 시스템 기획 및 로직 구현] (기여도 70%)

단순 A/B 선택이 아닌, 7단계 세부 선택 방식을 기획하여 유저의 자유도 향상.

플레이어의 선택 데이터를 배열(Array) 형태로 저장하고 결과창에 반영하는 로직 설계.

[직무 2, 게임 개발] (기여도 99%)

Figma를 활용하여 타이틀 화면, 인게임 HUD, 결과창 와이어프레임 및 프로토타입 제작.

3D 모션 그래픽 에셋을 게임 엔진에 최적화하여 임포트하고 애니메이션 컨트롤러 세팅.

## 🛠️ 문제 해결 및 개선 과정 (Trouble Shooting)

### 🚨 [문제 상황 요약, 예: UI 가시성 저하 문제]

상황(Situation): 초기 빌드 테스트 중, 배경의 화려한 이펙트 때문에 데미지 텍스트와 체력바가 잘 보이지 않는다는 피드백 접수.

원인 분석(Task): 배경과 UI 에셋 간의 명도 대비가 부족하고, UI에 아웃라인(외곽선) 처리가 부재했음.

해결 과정(Action):

Figma에서 배경색상과 UI 텍스트 간의 명도 대비(Contrast Ratio)를 재측정하여 기준치(4.5:1) 이상으로 Hex 코드 변경.

주요 정보 텍스트에 동적인 그림자(Drop Shadow) 효과 및 팝업 애니메이션 추가.

결과(Result): 2차 테스트 결과, 테스터 전원이 '현재 상태 및 피격 여부를 명확히 인지할 수 있다'고 응답하여 UX 크게 개선.
